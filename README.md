# UK Property AI Platform

A production-style AI platform that enables natural-language querying over UK property transaction data and regulatory documents using a Retrieval-Augmented Generation (RAG) architecture.

## Architecture
- FastAPI service layer
- Structured data ingestion from HM Land Registry
- Vector-based retrieval for unstructured documents (WIP)
- LLM-based response generation

## Current Status
- FastAPI service scaffolded
- Property transaction ingestion pipeline implemented
- RAG pipeline under active development

## Focus
This project prioritises system design, reliability, and data/AI integration rather than model training.
